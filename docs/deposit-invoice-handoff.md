- The generic deduction audit/terminal handling from the prior release remains unchanged. It permits precisely one repeat only for a literal 429 with a numeric `Retry-After` of 0–5 seconds. This avoids repeated challenge/login bursts for sequential Deal, Quote, service, customer and metadata reads. Existing one-time transient GET recovery remains; a VTiger 429 is retried only once when it carries a literal numeric `Retry-After` of 0–5 seconds. Login POSTs are never retried.
- `financialDraftWriteAllowsTransientRetry` is now hard-disabled for every financial Draft POST/PUT, including automatic Deposit creation. A lost/gateway response requires reconciliation; it can never cause a blind second Xero financial write. Existing per-document idempotency, claims and Draft-only constraints are retained.
